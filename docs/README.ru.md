> **Релиз-кандидат:** 3.0.0-rc.1 - предварительная версия следующего крупного
> релиза. В ней существенно изменены архитектура, установщик, сканирование,
> графы и OSINT-инструменты. Перед обновлением с 2.x сохраните резервные копии
> важных отчётов и настроек.

Laitoxx - настольная среда для OSINT и защитного анализа безопасности,
предназначенная для сбора, сопоставления и экспорта общедоступных технических
данных. Она объединяет специализированные инструменты расследования, локальный
анализ, графы связей и расширяемую систему Lua-плагинов в интерфейсе PyQt6.

Используйте Laitoxx только для систем и данных, которыми вы владеете или на
исследование которых у вас есть явное разрешение. Проект предназначен для
обучения, исследований, реагирования на инциденты и законного аудита
безопасности. Разработчики не несут ответственности за неправомерное
использование.

## Что нового в 3.0

- **Advanced Web Scanner:** сопоставляет DNS, регистрационные данные,
  сертификаты, маршрутизацию, открытые сервисы, threat intelligence, архивы и
  источники уязвимостей в едином графе доказательств и временной шкале. По
  умолчанию выполняется пассивный сбор; ограниченная локальная проверка
  включается явно.
- **TONgue:** строит связи между Telegram-профилями, TON-адресами,
  коллекционными Gifts, NFT и общедоступными транзакциями, формируя единый граф
  расследования и отчёты JSON/CSV.
- **Рабочая область Masscan:** заменяет прежний Nmap-сканер портов на Masscan
  1.3.2 с ограниченным сбором баннеров и локальным определением сервисов.
- **Интеграция CogniPass:** собирает закреплённый Zig-движок генерации паролей
  для текущего процессора и предоставляет отдельный графический интерфейс.
- **Новые инструменты расследования:** извлечение IOC, Domain Intelligence,
  структурированный Web Crawler, рабочая область стеганографии и Text Cipher с
  86 режимами.
- **Обновлённая основа:** feature-oriented архитектура `src`, ленивая загрузка
  инструментов, централизованная сетевая политика, системные каталоги данных,
  более безопасные Lua-плагины, модульные GUI-контроллеры и общие примитивы
  графов и отчётов.

Полный список изменений 3.0.0-rc.1 и база сравнения приведены в
[CHANGELOG.md](../CHANGELOG.md).

## Возможности

### OSINT и расследования

- Анализ IP с геолокацией, репутацией, данными об экспозиции и HTTP.
- Domain Intelligence с DNS, RDAP, HTTP, TLS, сертификатами и ограниченным
  обнаружением субдоменов.
- Username OSINT по каталогу из 500+ сайтов: контроль состояния провайдеров,
  генерация никнеймов, доказательства профилей, обработка аватаров и экспорт в
  граф.
- Проверка email и общедоступное обогащение данных.
- Конструктор Google dorks, поиск по локальным базам, поиск по изображениям и
  криминалистический анализ изображений.
- Глобальный поиск Wi-Fi/MAC по общедоступным данным позиционирования.
- Структурированный краулинг сайтов с контролем области, поиском endpoint и
  форм, отчётами и проекцией в граф.
- Извлечение IOC: IP, доменов, URL, email, телефонных номеров, хешей, JWT и
  имён пользователей.
- Расследования TONgue для Telegram, TON-кошельков, Gifts, NFT, истории
  владения, перемещений и общедоступных доказательств.

### Анализ веб-приложений и сети

- Advanced Web Scanner с происхождением доказательств, уровнями уверенности,
  квотами, кешированием, временными шкалами и графами связей.
- Опциональная локальная проверка через Naabu, httpx, Nuclei и уже
  установленный WPScan.
- Обнаружение портов через Masscan с локальным анализом баннеров и сервисов.
- HTTP Inspector, определение технологий, пассивный аудит CMS и анализ JWT.
- Проверки TLS, CORS, перенаправлений и заголовков безопасности.
- Калькулятор CIDR для IPv4/IPv6 и тестер регулярных выражений.

### Локальные утилиты

- Просмотр метаданных, оценка приватности, очистка и анализ файлов.
- Встраивание, извлечение и анализ стеганографии, расчёт вместимости,
  аутентифицированные и зашифрованные контейнеры данных.
- Хеширование текста, определение типа хеша и генерация радужных таблиц.
- Text Cipher с 86 локальными кодировками, классическими шифрами, текстовыми
  операциями, хешами, преобразованиями чисел, дат, цветов и символов.
- Обычный генератор паролей и отдельный целевой генератор CogniPass.
- Нативный редактор графов связей с раскладками, стилями, импортом, экспортом,
  анализом и отменяемым редактированием.

### Платформа приложения

- Настольный интерфейс PyQt6 с темами, настройкой фона, палитрой команд,
  управлением задачами и четырьмя языками интерфейса.
- Обнаружение и настройка Lua-плагинов, проверка синтаксиса, ограниченная среда
  выполнения и host API для графов и OSINT-сервисов.
- Общая маршрутизация через SOCKS5. При включённой защите прокси прямые DNS- и
  socket-подключения блокируются, чтобы совместимые инструменты не могли
  незаметно обойти заданный маршрут.
- Структурированные отчёты, общие графы доказательств, локальный кеш, учёт
  rate limit, совместная отмена задач и сохранение частичных результатов.

## Требования

- Windows, Linux или macOS на поддерживаемой платформе x86/x64 или ARM64.
- Python **от 3.10 до 3.13**. Python 3.14 не поддерживается этим релизом,
  поскольку часть стека PyQt и зависимостей пока несовместима.
- Доступ в интернет для установки зависимостей и онлайн-провайдеров OSINT.
- Рекомендуется Git. Он также используется как проверяемый резервный способ,
  если закреплённый архив исходников нельзя скачать обычным способом.
- Для сборки Masscan из исходников:
  - Linux/FreeBSD: `make` и C-компилятор, например GCC или Clang;
  - macOS: `make` и Xcode Command Line Tools;
  - Windows: MinGW с `mingw32-make` и GCC или Clang, а также совместимый с
    Npcap драйвер для сканирования.
- Для запуска Masscan обычно требуются права администратора/root или
  соответствующая capability для raw-пакетов. Установщик не предоставляет эти
  права автоматически.

## Установка

### Клонирование через Git

```sh
git clone https://github.com/laitoxx/Laitoxx-Multi-Tool.git
cd Laitoxx-Multi-Tool
```

Также можно выбрать **Code → Download ZIP** на GitHub, распаковать архив и
открыть терминал в полученном каталоге.

### Linux и macOS

```sh
chmod +x install.sh
./install.sh
python3 start.py
```

### Windows

Запустите `install.bat` из Command Prompt или двойным щелчком, затем запустите
приложение:

```cmd
install.bat
python start.py
```

Установщик создаёт `venv`, устанавливает Python-зависимости, собирает
CogniPass, устанавливает проверенные автономные версии сканеров и собирает
закреплённый исходный код Masscan для текущей ОС и процессора. Отсутствующий
компилятор, неподдерживаемая платформа, ошибка загрузки или контрольной суммы,
блокировка файла либо сбой зависимости отображаются явно. Установщик не
сообщает об успешном завершении, если обязательная группа компонентов не была
установлена.

Для этого релиза закреплены следующие версии:

| Компонент | Версия или источник | Способ установки |
| --- | --- | --- |
| CogniPass | commit `1062c39102a8868e2a48a7496047eb24497d67bd` | локальная оптимизированная сборка Zig |
| Masscan | 1.3.2 | сборка проверенных официальных исходников |
| Nuclei | 3.11.0 | проверенный автономный релиз |
| httpx | 1.10.0 | проверенный автономный релиз |
| Naabu | 2.6.1 | проверенный автономный релиз |

WPScan является необязательным и не загружается автоматически, поскольку его
официальный CLI требует Ruby и нативных зависимостей сборки. Если `wpscan` уже
доступен в `PATH`, Laitoxx обнаружит его; без него остальные пассивные и активные
этапы продолжат работать.

## Запуск и обновление

Всегда запускайте проект через `start.py`. Он проверяет наличие локального
виртуального окружения, выполняет проверку подключения и запускает GUI с
правильным путём импорта `src`.

```sh
python3 start.py   # Linux/macOS
python start.py    # Windows
```

Установки, полученные через Git, могут проверять настроенный upstream перед
запуском. ZIP-копии и снимки исходников без метаданных `.git` корректно
пропускают проверку обновлений.

Изменяемые данные хранятся вне каталога исходников:

- Linux: `${XDG_DATA_HOME:-~/.local/share}/laitoxx`
- macOS: `~/Library/Application Support/Laitoxx`
- Windows: `%LOCALAPPDATA%\Laitoxx`

Для выбора другого каталога задайте `LAITOXX_DATA_DIR`.

## Настройка Advanced Web Scanner

При первом запуске Advanced Web Scanner открывает обязательную проверку
настроек провайдеров. Базовая цепочка использует общедоступные endpoint, а также
бесплатные ключи IPinfo Lite и AbuseIPDB. Дополнительные провайдеры включаются
отдельно. Поддерживаются следующие переменные окружения:

```text
IPINFO_TOKEN, OTX_API_KEY, ABUSEIPDB_API_KEY, NVD_API_KEY,
SHODAN_API_KEY, VIRUSTOTAL_API_KEY, URLSCAN_API_KEY,
GREYNOISE_API_KEY, GITHUB_TOKEN, VULNCHECK_API_TOKEN,
WPSCAN_API_TOKEN, HACKERTARGET_API_KEY, WHOISJSON_API_KEY,
BOTOI_API_KEY, LEAKIX_API_KEY, CERTSPOTTER_API_TOKEN
```

Пути к локальным инструментам можно переопределить через
`LAITOXX_<TOOL>_PATH`. Квоты провайдеров, периоды ожидания, состояние кеша,
частичные ошибки и временные метки доказательств сохраняются в отчётах.
Технические подробности приведены в
[`advanced_web_scanner/README.md`](../src/laitoxx/features/osint/advanced_web_scanner/README.md).

## Плагины

Laitoxx поддерживает Lua-плагины в `lua_plugins/`. Runtime 3.0 предоставляет
ограниченную среду и явные host-сервисы вместо неограниченного доступа Lua к
процессу. Начните со встроенного шаблона и руководства разработчика:

- [Шаблон плагина](../lua_plugins/_template.lua)
- [Руководство по разработке плагинов](pluginBuilding.ru.md)

Авторам плагинов, переходящим с 2.x, следует проверить изменения host API до
загрузки существующего плагина в 3.0.0-rc.1.

## Архитектура и проверка

Приложение использует feature-oriented структуру пакетов:

- `laitoxx.app` - composition root, каталог инструментов и runtime плагинов;
- `laitoxx.core` - настройки, локализация, пути, TLS и сетевая политика;
- `laitoxx.features` - независимые OSINT-, сетевые, web-audit-, crypto- и
  utility-компоненты;
- `laitoxx.interfaces.gui` - представление и контроллеры PyQt;
- `laitoxx.shared` - общие примитивы графов, выполнения и отчётов.

Обработчики инструментов задаются путями импорта и загружаются только при
выборе, поэтому сбой необязательной функции не мешает запуску основного
интерфейса. Правила зависимостей и расширения описаны в
[ARCHITECTURE.md](ARCHITECTURE.md).

Основные проверки для сопровождающих:

```sh
venv/bin/python scripts/verify_dependencies.py
venv/bin/python scripts/check_structure.py
venv/bin/python scripts/verify_architecture.py
```

Runtime-аудиты ядра, GUI, воркеров, провайдеров, текстовых преобразований,
стеганографии, Web OSINT и TONgue находятся в каталоге `scripts/`.

## Примечания к релиз-кандидату

- Это предварительный релиз. В отчёте о регрессии указывайте ОС, версию Python,
  полный текст ошибки и шаги воспроизведения.
- Активная сетевая проверка отключена до явного подтверждения для текущего
  сканирования. Не сканируйте чужую инфраструктуру без разрешения.
- Полнота онлайн-данных зависит от ключей, квот, доступности и типа цели.
  Частичные результаты ожидаемы и сохраняются вместе с состоянием источника.
- Локальные сканеры намеренно отключаются при включённой защите SOCKS-прокси,
  поскольку raw/local инструменты не могут гарантировать использование этого
  маршрута.
